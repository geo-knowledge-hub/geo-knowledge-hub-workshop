## Workshop materials

This directory holds the materials that complement the GEO Knowledge Hub workshop. The following materials are available:

**NEOSS 2026 bundle**

The example files used in the hands-on activities of the SA-GEO Knowledge Hub Training — a climate projection study with its processing script, result tables, presentation and data management plan. Participants use the bundle to publish a Knowledge Package by hand, and again to produce one with AI assistance.

[Click here to access](./neoss-2026/)

**Generic Knowledge Package**

An example of a Knowledge Package composed of multiple elements, including `article`, `dataset`, `software` and `user story`. It is a [Knowledge Package Repository](https://github.com/geo-knowledge-hub/geo-package-loader#knowledge-package-repository), so it can be published to the GEO Knowledge Hub with the package loader.

[Click here to access](./example-package/)
